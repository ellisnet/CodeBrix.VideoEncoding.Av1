THIRD-PARTY SOFTWARE NOTICES AND INFORMATION

CodeBrix.VideoEncoding.Av1 is an AV1 video encoder for .NET: a managed wrapper
together with the native codebrix_av1 libraries it P/Invokes into. Two kinds
of third-party content are in this repository, and both are covered below:

  1. THE VENDORED SOURCE. av1-native-tools/aom/ is an unmodified copy of the
     libaom release source (Alliance for Open Media,
     https://aomedia.googlesource.com/aom), and av1-native-tools/nasm/ an
     unmodified copy of the NASM assembler release (https://www.nasm.us),
     committed so the native libraries can be rebuilt from this repository
     alone. The tarballs are kept in av1-native-tools/upstream-downloads/; their
     identity (URL, version, SHA-256) is recorded in
     av1-native-tools/UPSTREAM.txt.

  2. THE SHIPPED BINARIES. The package's runtimes/<rid>/native/ folders contain
     libcodebrix_av1.so / libcodebrix_av1.dylib / codebrix_av1.dll, each of
     which statically links libaom compiled from exactly that source (encoder
     only), together with a small C shim (av1-native-tools/shim/) written for
     this repository.

libaom is licensed under the BSD 2-Clause licence - the same licence as this
repository - together with the Alliance for Open Media Patent License 1.0. Both
texts are reproduced in full below.

HOW THE NOTICES TRAVEL WITH THE BINARIES
    Every native build writes LICENSE-Aom.txt beside the binary in
    runtimes/<rid>/native/, composed by one generator
    (av1-native-tools/licenses/compose-license-aom.sh) and byte-identical for
    every RID: libaom's LICENSE, its PATENTS file and the licence of every
    third-party component that is compiled into the encoder. So the texts
    physically travel inside the NuGet package next to every native library,
    on every platform - in addition to this file.

WHAT IS BUILT, AND WHAT IS NOT
    Only libaom's AV1 ENCODER is compiled (CONFIG_AV1_DECODER=0, high bit depth
    on), as a static library inside the shim. The libaom command-line tools,
    examples, documentation and test suite are NOT built; the googletest copy
    under aom/third_party/googletest, libwebm and the other third_party folders
    not listed below are present only because the release is vendored
    unmodified, and nothing from them is compiled or shipped.

    Third-party code that IS compiled into the shipped encoder (verified from
    the link of the native build; full texts below):
      - FAST corner detector, aom/third_party/fastfeat (BSD-3-Clause,
        Copyright (c) 2006, 2008 Edward Rosten)
      - vector, aom/third_party/vector (MIT, Copyright (c) 2016 Peter
        Goldsborough)
      - x86inc.asm, aom/third_party/x86inc (ISC, Copyright (C) 2005-2012 x264
        project) - x86-64 builds only

    NASM IS A BUILD-TIME TOOL ONLY. It assembles libaom's x86-64 SIMD code
    while the natives are built; no NASM code is compiled into, linked into or
    shipped with any binary. Its licence (BSD-2-Clause) is reproduced below for
    completeness because its source is vendored in this repository.

WHAT WAS MODIFIED
    NOTHING. No file in av1-native-tools/aom/ or av1-native-tools/nasm/ has
    been edited, renamed, reformatted, added or deleted.
